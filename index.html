GitHub Pages를 통해 무료로 개인 웹사이트(홈페이지)를 게시하기 원하시는 것 같습니다. 깃허브에 저장하고 무료로 호스팅(웹 게시)하는 전체 절차를 안내해 드립니다. 1단계: GitHub 저장소(Repository) 이름 설정하기 깃허브 웹사이트에 무료로 홈페이지를 띄우려면 저장소의 이름을 올바르게 지정하는 것이 좋습니다. 가장 쉬운 방식 (기본 도메인 제공): 저장소 이름을 내아이디.github.io 형태로 만듭니다. 예시: 계정명이 Ingyuahjae라면 저장소 이름을 Ingyuahjae.github.io로 생성합니다. 이렇게 만들면 인터넷 주소창에 [https://Ingyuahjae.github.io](https://Ingyuahjae.github.io) 를 입력했을 때 웹사이트가 바로 접속됩니다. 2단계: 소스 코드 저장하기 (index.html) GitHub에서 새로 만든 저장소(또는 사용할 저장소)로 이동합니다. Add file → Create new file을 클릭합니다. 파일 이름을 반드시 index.html로 입력합니다. (GitHub Pages는 index.html을 기본 메인 페이지로 인식합니다.) 아래 파일 작성 창에 보내주신 HTML 코드 전체를 복사하여 붙여넣습니다. 우측 상단의 Commit changes... 버튼을 누른 후, 한번 더 Commit changes를 눌러 저장합니다. 3단계: GitHub Pages 무료 호스팅 활성화하기 해당 레포지토리 상단의 Settings (톱니바퀴 아이콘) 탭을 클릭합니다. 왼쪽 메뉴에서 Pages를 클릭합니다. Build and deployment 항목 아래: Source: Deploy from a branch 선택 Branch: main (또는 master) 선택 / 폴더는 / (root) 선택 Save 버튼을 누릅니다. 4단계: 접속 확인하기 저장 후 약 1~3분 정도 기다리면 Settings → Pages 메뉴 상단에 "Your site is live at https://..." 라는 안내 메시지와 함께 웹사이트 주소가 표시됩니다. 해당 주소를 클릭하면 스마트폰이나 컴퓨터 어디서든 작성하신 웹사이트에 접속할 수 있습니다. 💡 유용한 팁 내용을 수정할 때: GitHub의 index.html 파일로 들어가 연필 아이콘(Edit)을 눌러 코드를 수정하고 Commit changes를 누르면 몇 분 내로 인터넷 사이트에 자동으로 반영됩니다. 토목 팀 업무 & 세계여행 관리 시스템
